
# 动态定投执行器（000083）

## 运行步骤
1. 安装依赖：
   ```bash
   pip install akshare pandas
   ```

2. 把这三个文件放到同一目录：
   - dynamic_dca_000083.py
   - config.json
   - state.json

3. 运行（每周一次即可）：
   ```bash
   python dynamic_dca_000083.py
   ```

4. 输出：
   - 控制台打印本周建议：固定投、动态投、准备金余额、触发理由（MA200偏离）。
   - 生成/更新 `dca_log.csv` 用于长期复盘。

## 参数说明（config.json 可改）
- weekly_budget：每周预算（默认 200）
- fixed_ratio：固定投入占比（默认 0.40 → 建议 40% 固定 / 60% 动态 起步）
- reserve_cap_months：准备金上限（月数）
- max_weekly_multiple：单周最大投入 = 预算 × 倍数（含固定部分）
- ma200_low/ma200_mid：相对200日均线偏离阈值（%），低于 ma200_low 视为“低估”，介于两者为“合理”，高于 ma200_mid 为“高估”
- alloc_low/mid/high：对应三档估值时，**动态准备金动用比例**
- mode_grid：是否启用“4%网格模式”，作为辅助信号（默认关闭）
- grid_step_pct：网格阶距（%）
- reserve_sweep_days：若持续未触发低估，建议把准备金在 3 个月内“等额扫入”

## 说明
- 000083 为主动基金，估值不可见；程序用 **中证主要消费指数（sh000932）** 作为估值与节奏代理；若取数失败回退到 **沪深300（sh000300）**。
- 若你更偏好其他代理，比如“中证消费50”“标普中国消费”，可把 `proxy_index` 修改为相应交易所前缀代码（如 shXXXXXX / szXXXXXX）。
- 本程序只做“金额建议与记录”，**不连接任何交易平台**；下单请在支付宝/券商自行完成。
