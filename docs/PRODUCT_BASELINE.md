# Product Baseline

CompoundInterestPlan 是一个帮助投资新手在有限时间内坚持价值定投、平衡牛熊、控制情绪、定期复盘，并逐步提高判断力的 Agent 投资工作台。

## Value-DCA 框架

### 核心—卫星架构
- 核心：宽基/策略型基金（沪深300、中证500等）持仓 60-70%
- 卫星：行业/主题基金（消费、医药、科技等）持仓 30-40%

### 双模式
- 固定 DCA：按周固定金额定投，适用于趋势良好、估值中位的标的
- 动态 DCA：根据 MA200 偏离度调整定投金额，低估多买、高估少买/观察

## 风控三层
1. 资产层面：单只基金不超过 MA200 阈值
2. 组合层面：同主题不超过 1 只可操作
3. 行为层面：用户确认所有动作，永不自动交易

## 复盘学习
- 每周冻结计划 → 自动生成决策日志
- 每月回顾：决策质量、行为偏差、规则是否需要调整
- 知识沉淀：LessonRecord / RuleChangeProposal

## 禁止事项
- no_auto_trade：永不自动下单
- no_auto_confirm：永不自动确认
- no_pool_deduction：只由用户确认后扣减
