# Hermes Desktop Usage — 用户最终使用方式

> v0.7: 不再手动输入 python 命令。自然语言一句搞定。

## 每天的使用流程

### 1. 打开 Hermes

### 2. 输入

```
打开复利投资系统
```

Hermes 自动完成：
- 启动 FastAPI（port 8701）
- 启动 Hermes Scheduler
- 打开 GUI（http://localhost:8501）
- 返回系统状态

### 3. 在 GUI 查看状态

浏览器打开 `http://localhost:8501`：
- 📊 总览：所有基金状态
- 🔍 基金详情：偏离度、估值层级、建议金额
- 📈 持仓 & 交易：录入实际交易
- 💵 资金池：管理准备金
- 📅 周复盘：每周投资总结

### 4. 自动化运行

Scheduler 自动执行：

| 时间 | 任务 |
|------|------|
| 每天 17:00 | 每日采样 → 生成日报 |
| 每天 17:10 | 异常检查 → 生成告警 |
| 周四 17:20 | 周报生成 |
| 周五 17:00 | 数据库备份 |

### 5. 真实交易仍需 GUI 确认

- 系统建议 ≠ 自动下单
- 在 GUI 的「持仓 & 交易」标签页手动确认交易
- from_pool 交易自动扣减准备金

## 自然语言命令速查

| 你说 | Hermes 执行 |
|------|-----------|
| 打开复利投资系统 | API + Scheduler + GUI 全启动 |
| 打开 GUI | 只打开浏览器界面 |
| 今天能不能买 | 查询 latest plan → PASS/BLOCKED |
| 跑一下每日采样 | 手动触发采样 |
| 生成周报 | 生成周度复盘 |
| 打开异常报告 | 查看最新告警 |
| 备份数据库 | 安全备份 |
| 关闭系统 | 停止所有管理进程 |

## 禁止事项

- ❌ 不需要手动 `python -m src.app.api`
- ❌ 不需要手动 `python -m hermes.runtime.scheduler`
- ❌ 不需要手动 `streamlit run`
- ❌ 系统不会自动下单
- ❌ 系统不会自动确认交易
