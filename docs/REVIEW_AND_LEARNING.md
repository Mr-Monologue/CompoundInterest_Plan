# Review & Learning System v1

## 目标
帮助用户从每一次投资决策中学习，逐步提高判断力。

## 核心流程
1. 每周：周计划冻结 → 自动生成决策日志 (DecisionJournalEntry)
2. 每月：月度回顾 → 对比预期与实际
3. 每季：规则评估 → 是否调整策略参数

## DecisionJournalEntry
- 投资逻辑快照
- 预期场景
- 失效条件
- 已知未知
- 用户笔记

## 未来扩展 (v2.2)
- 过程质量评分
- 行为偏差标签
- LessonRecord
- RuleChangeProposal
- 用户能力评分
