# v2.1 Four-Week Pilot Plan

## Asset Scope
- 1-2 core assets (broad market/index)
- 1-2 satellite assets (sector/theme)
- 0-1 defensive asset (bond/money market)

## Weekly Flow
1. Fetch market data → Data Quality Audit
2. Build WeeklyInvestmentPlan
3. User approves/skips/defers
4. User executes on external platform
5. User records execution facts
6. User confirms reconciliation
7. Generate WeeklyReview
8. Close review → Next cycle

## Success Criteria
- 4 consecutive weeks completed
- All amounts traceable
- Zero mock advice
- Zero auto-trade
- Zero auto-confirm
- Zero auto pool deduction
- All new Transactions have source_execution_id
